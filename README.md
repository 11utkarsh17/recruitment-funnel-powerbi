# Recruitment Funnel Dashboard (Power BI)

A Power BI dashboard that tracks how candidates move through the hiring process, from application to offer, and shows where the process is slow or losing people.

## Questions it answers
- How many candidates drop off at each stage?
- Which sourcing channels produce the most hires, and at what cost?
- How long does hiring take in each department?
- How are hiring numbers changing month to month?

## KPIs
Total applications, candidates screened, candidates interviewed, offers made, candidates hired, average time to hire.

## Dashboard views
- Candidates by recruitment stage
- Stage-to-stage conversion rate
- Hires by source
- Cost per hire by source
- Time to hire by department
- Monthly hiring trend

## Filters
Department, source, job level, final status.
